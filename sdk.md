# Plugin SDK

The public SDK exposes services, callbacks, structures, and enums to plugins.
Use the public SDK contracts rather than game addresses or private loader details.

## Start here

- [API Reference](/en/sdk/api)
- [DataTableService](/en/sdk/api/services/data-tables)
- [getTable](/en/sdk/api/services/data-tables/get-table)
- [Contributing](/en/contributing)

The SDK includes a complete data-table sample in `examples/data-tables`.
Use it to check service lookup and the table-load callback before adapting the short reference example.

SDK guides and examples can receive community edits. Maintainers control API reference pages.
