# Contributing

Help improve guides, examples, and reference explanations.

## Access

Anyone can read published pages. An administrator creates accounts and grants editor access for this local preview.
Public registration and email recovery are not enabled yet.

Editors can create and edit pages below `players/`, `modders/`, `sdk/guides/`, and `sdk/examples/`.
Moderators can move or delete pages and review history. Administrators manage accounts, permissions, and integration settings.
Maintainers control `sdk/api/` and the page templates.

## Editing rules

- Use short sentences and explain unfamiliar terms.
- Check facts against current project sources or a repeatable test.
- Identify the game or SDK versions that you tested.
- Preserve limits, exceptions, and save-backup warnings.
- Do not publish passwords, private logs, or other people's email addresses.
- Do not copy another project's full documentation without permission.

Edits publish immediately.
Moderators can compare revisions and restore an earlier version.
