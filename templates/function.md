# Function page template

Copy this structure when a maintainer adds an SDK reference page.
Do not use example field values as an API contract.

## Purpose

Explain what the function does before describing its parameters.

## Signature

Copy the exact public SDK declaration. Name its header and owning service.

## Parameters

Explain each parameter, required initialization, and permitted values.

## Return value

Explain success and the relevant failure results. Do not invent undocumented guarantees.

## Safety rules

Describe memory ownership, pointer lifetime, execution restrictions, and supported versions when relevant.

## Example

Add a small, tested example. State the conditions the example assumes.

## Related pages

Link the owning service, related functions, structures, enums, and guides.
