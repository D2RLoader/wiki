# Table field template

Use this structure for a field in an Excel table.
Keep source documentation separate from behavior verified in D2RLoader.

## Table and field

Name the table, field, and related fields. Explain the field's purpose.

## Source

Name the documentation source and version. Preserve required attribution.

## Verified versions

List the D2RLoader and game versions tested. Use `Not yet checked` for an unverified claim.
A Blizzard 3.3.0 description is not proof of behavior in D2RLoader's 3.1.1.4 target.

## Values and limits

Explain valid values, defaults, indexes, masks, and limits when known.
For a mask or index, include a small verified example.

## Example

Show the change and the result from a repeatable test.

## Community notes

Keep corrections, uncertainty, and warnings separate from the source description.
Do not copy Blizzard's complete text without confirmed redistribution permission.
